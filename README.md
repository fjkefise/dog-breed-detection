# 🐶 Dog Breed Detection & Classification Project

Проект для детекции собак на изображениях и классификации их пород с использованием YOLO и FastAPI.

## ✨ Особенности
- **Детекция собак**: Модель YOLO11n для обнаружения собак на изображениях
- **Классификация пород**: Разделение на 4 породы: Чихуахуа, Японский спаниель, Мальтийская болонка, Пекинес
- **Веб-интерфейс**: Простой фронтенд для загрузки изображений
- **REST API**: Документированный FastAPI с автогенерацией OpenAPI
- **Оптимизированные модели**: ONNX-формат с квантованием для ускорения инференса

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/fjkefise/dog-breed-detection
cd dog_breed_project
```

### 2. Создание виртуального окружения
```bash
python -m venv .venv
```

### 3. Активация окружения
```bash
# Linux/macOS
source .venv/bin/activate

# Windows
.venv\Scripts\activate
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Запуск приложения
```bash
uvicorn app.main:app --reload --port 8077
```

### 6. Доступ к приложению
- **Веб-интерфейс**: http://localhost:8077/static/index.html
- **Документация API**: http://localhost:8077/docs
- **Альтернативная документация**: http://localhost:8077/redoc

## 🔧 Использование

### Через веб-интерфейс
1. Откройте http://localhost:8077/static/index.html
2. Загрузите изображение с собакой
3. Нажмите "Detect & Classify"
4. Получите результаты детекции и классификации

### Через API
```bash
# Детекция собак
curl -X POST -F "file=@your_image.jpg" http://localhost:8077/detect

# Классификация породы
curl -X POST -F "file=@your_image.jpg" http://localhost:8077/classify

# Проверка здоровья сервиса
curl http://localhost:8077/health
```

## 🏗 Архитектура

### Модели
- **Детекция**: YOLO11n, обученная 30 эпох, конвертирована в ONNX
- **Классификация**: Сверточная нейросеть, обученная на датасете из 4 пород

### Оптимизация
- **Упрощение графов**: ONNX Simplifier
- **Квантование**: Dynamic quantization для ускорения инференса
- **Формат**: ONNX для кроссплатформенной совместимости

### API
- **Фреймворк**: FastAPI с асинхронной обработкой
- **Документация**: Автогенерация OpenAPI 3.0
- **Статические файлы**: Servestatic для фронтенда
